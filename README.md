# **Project Title**

The Desert Road

# **Description**

This is an environment set in Unreal Engine, with talkable NPC's, set on a road in a post apocalyptic style desert.

# ** Build/Run steps:**

Go to code and download the ZIP file of this project, once downloaded, extract the folder to a suitable folder in your desktop.
Before running the project, make sure to right click the unreal engine project and choose: Generate Visual Studio project files. Once you finally run the project you should be asked to rebuild it, which you can accept. Once that is done everything should run smooth.
